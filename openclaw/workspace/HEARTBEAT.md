# HEARTBEAT — Периодические задачи Innova AI

- [ ] Проверить наличие новых сообщений в каналах (Telegram, Slack)
- [ ] Обновить дневные заметки в memory/YYYY-MM-DD.md
- [ ] Проверить актуальность курса валют (USD/UAH, EUR/UAH) для инвестиционных расчётов

## Еженедельно

- [ ] Мониторинг изменений в законодательстве Украины (Верховна Рада, КМУ)

- [ ] Сводка по активным консультациям за неделю

## Ежемесячно

- [ ] Ревизия MEMORY.md — удаление устаревших записей
- [ ] Анализ часто задаваемых вопросов — обновление шаблонов ответов
- [ ] Проверка актуальности шаблонов документов
- [ ] Отчёт по метрикам: количество консультаций, распределение по направлениям

## Триггеры

- **Новый закон/постановление** → обновить релевантные скиллы и шаблоны
- **Новый клиент** → запустить client-intake скилл
- **Дедлайн по задаче клиента** → напомнить за 3 дня и за 1 день
- **Изменение ставок НБУ** → уведомить инвестиционное направление
