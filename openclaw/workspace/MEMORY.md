# MEMORY — Долгосрочная память Innova AI

- Innova Consulting Group работает с 2012 года
- Основной рынок — Украина, расширение в ЕС
- 7 направлений: юриспруденция, аудит, маркетинг, недвижимость, инвестиции, обучение, HR
- Входит в каталог DANs (подтверждение качества)
- Клиентская база: МСБ, стартапы, IT-компании, агробизнес

## Актуальный контекст

- Украина находится в состоянии военного положения — учитывать ограничения НБУ и мобилизационные аспекты при консультировании
- Евроинтеграционные процессы — адаптация к нормам ЕС
- Налоговая реформа — следить за изменениями в НКУ
- Diia (Дія) — цифровые государственные сервисы, учитывать при консультировании
