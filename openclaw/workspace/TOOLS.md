# TOOLS — Инструменты и ресурсы Innova AI

## Внешние сервисы

### Государственные реестры Украины
- **Єдиний державний реєстр** (ЄДР) — проверка юридических лиц и ФОП: https://usr.minjust.gov.ua/
- **Youcontrol** — бизнес-аналитика и проверка контрагентов
- **Opendatabot** — открытые данные о компаниях Украины
- **Дія** — цифровые государственные сервисы: https://diia.gov.ua/

### Нормативная база
- **Верховна Рада** — законодательство: https://zakon.rada.gov.ua/
- **НБУ** — нормативные акты Нацбанка: https://bank.gov.ua/
- **ДПС** — налоговая служба: https://tax.gov.ua/
- **НКЦПФР** — регулятор фондового рынка: https://www.nssmc.gov.ua/

### Инструменты для работы
- **Система электронного документооборота** — для подготовки и подписания документов
- **CRM** — для управления клиентской базой
- **Бухгалтерские системы** — 1С, BAS, M.E.Doc для работы с отчётностью
